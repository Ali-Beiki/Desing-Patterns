# Prototype Design Pattern - PHP Implementation

این پروژه پیاده‌سازی ساده‌ای از **الگوی طراحی Prototype** در زبان PHP است.

## 🧠 الگوی طراحی Prototype چیست؟

الگوی Prototype یکی از الگوهای دسته‌ی **Creational (ایجادی)** است. این الگو به شما اجازه می‌دهد تا اشیاء جدید را با **کپی کردن (clone)** یک شیء نمونه (prototype) بسازید، به‌جای اینکه هر بار آن‌ها را از صفر ایجاد کنید.

این کار زمانی مفید است که ساخت شیء جدید زمان‌بر یا پیچیده باشد، یا بخواهیم چندین نسخه‌ی سفارشی‌شده از یک نمونه‌ی پایه داشته باشیم.

---

## ⚙️ توضیح روند پیاده‌سازی

در این پروژه:

1. ابتدا یک شیء اولیه به‌عنوان **prototype** ساخته می‌شود (مثلاً یک کتاب های مربوط به SQL).
2. با استفاده از `clone`، نسخه‌های جدیدی از این شیء ایجاد می‌شود، که هر کدام مستقل از شیء اولیه هستند.
3. سپس با استفاده از متدهایی مانند `set_name()`، به هر نسخه‌ی کپی شده یک نام اختصاصی داده می‌شود.
4. در نهایت، اطلاعات مربوط به موضوع (topic) و نام (name) هر کتاب چاپ می‌شود تا نشان داده شود که هر شیء، نمونه‌ای جداگانه و قابل تنظیم از prototype اولیه است.

---

## 🎯 هدف

هدف از این پیاده‌سازی نشان دادن قدرت و سادگی استفاده از `clone` در PHP برای ایجاد اشیاء جدید از روی نمونه‌ی اولیه است؛ بدون وابستگی به ساختار کلاس و با انعطاف‌پذیری بالا برای سفارشی‌سازی هر کپی.
